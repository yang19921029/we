# 数据标注平台用户操作手册

本手册介绍登录、角色权限、项目与数据准备、任务标注、质量审核和数据交付。页面会根据账号角色显示菜单；如果本手册提到的菜单在账号中不可见，请联系平台管理员核对角色和项目成员关系。

## 1. 登录与账号安全

### 登录和退出

1. 打开平台登录页，输入登录账号（也可使用作为账号的手机号）和密码。
2. 点击“登录”。验证成功后进入标注工作台。
3. 点击页面右上角账号名称，可查看账号角色并打开“账号安全”；点击“退出登录”结束当前会话。
4. 账号名称旁的数字表示最近 5 分钟内有活动的启用账号数。同一账号的多个登录会话只计一次；浏览器关闭或网络中断后，人数最多可能延迟 5 分钟更新。

### 修改密码和绑定找回邮箱

1. 点击右上角账号名称，选择“账号安全”。
2. 在“修改密码”区域输入当前密码、新密码和确认密码，然后点击“修改密码”。新密码长度为 8 至 256 个字符。
3. 在“找回密码邮箱”区域填写本人可访问的邮箱，点击“发送验证码”；收到邮件后填写验证码并点击“验证并绑定邮箱”。
4. 验证通过后，邮箱用于登录页的忘记密码流程。验证码 10 分钟内有效，且发送有间隔限制。

若 SMTP 邮件服务未配置，系统无法发送验证码。请联系管理员配置邮件服务，或由管理员在“人员与权限”中重置密码。绑定并验证邮箱后，登录页选择“忘记密码？”、填写账号并获取验证码，设置新密码后返回登录。

## 2. 角色和菜单权限

菜单会按角色显示；账号安全入口对所有已登录用户开放。角色菜单如下：

| 角色 | 可见菜单 | 主要用途 |
|---|---|---|
| 超级管理员 | 全部菜单 | 全局账号、项目、数据和平台管理 |
| 项目管理员 | 全部菜单 | 跨项目管理、账号维护和业务管理 |
| 任务负责人 | 首页、数据标注、项目与任务管理、规范与帮助、标签体系管理 | 管理可访问项目的数据集和标注任务 |
| 标注员 | 首页、数据标注（仅数据打标）、规范与帮助 | 完成分配给自己的标注任务 |
| 审核员 | 首页、质量管理、规范与帮助 | 检查标注、审核通过或退回修改 |
| 数据分析员 | 首页、数据标注、规范与帮助、统计分析、数据交付与导出 | 查看数据、汇总指标和导出数据 |

项目成员关系会进一步限制项目范围。除超级管理员和项目管理员外，其他角色只能访问已加入项目的数据及相关任务；未加入对应项目时，看不到该项目数据，或相关操作会提示无权访问。隐藏菜单不等于授予了接口权限，敏感操作仍由服务端按角色检查。

## 3. 管理员：账号、组织、项目和成员

### 创建和维护账号

仅超级管理员和项目管理员可使用“人员与权限”：

1. 点击“新增人员”，输入登录账号、至少 8 个字符的初始密码并选择角色，创建账号。
2. 账号列表中可查看角色和启用状态；修改角色时在角色下拉框选择新角色。
3. 点击“编辑 / 重置密码”可修改账号或设置新密码；重置密码时填写新密码，留空则不修改密码。
4. 使用“禁用”阻止账号继续登录；再次点击“启用”可恢复账号。禁用会使已有会话失效，不会删除历史记录。

至少保留一个启用的管理员账号。给用户分配满足工作需要的最小角色，并在下一步将用户加入对应项目。

### 创建组织和项目

1. 打开“项目与任务管理”下的“组织与项目”。
2. 点击“创建组织”，填写组织名称和说明。
3. 点击“创建项目”，选择所属组织，填写项目名称和说明。
4. 在“项目成员”区域选择项目，点击“添加成员”，选择已启用账号。只有加入项目的普通用户才能访问该项目的数据集和任务。
5. 不再需要访问时，在成员列表中点击“移除”。移除项目成员不会删除其历史操作或标注记录。

超级管理员和项目管理员可跨项目管理；任务负责人可以查看有权访问的项目，但不能通过此页面创建组织、项目或维护项目成员。

## 4. 管理员或任务负责人：准备数据和创建任务

推荐按“项目 → 数据集 → 标签体系 → 任务 → 标注 → 审核 → 交付”的顺序操作。

### 创建数据集并导入数据

1. 打开“数据标注”下的“数据集管理”，点击“创建数据集”。
2. 填写名称和说明，并选择所属项目。任务负责人只能为其有权访问的项目创建数据集。
3. 数据集创建后点击“导入数据”，选择目标数据集并上传文件。
4. 支持 CSV、JSON、JSONL/NDJSON 文件；单个文件最大 1 GB，记录数不限，单条记录最大 50 MB。JSON 文件可为对象数组、包含 `items` 数组的对象或单个对象；每条记录必须是对象。CSV 文件首行为字段名。
5. 点击“预检文件”，等待系统检查完整文件并查看记录数量、字段和最多 10 条样例；确认无误后点击“确认并导入”。预检不会写入数据，确认导入时需要再次上传文件。大文件预检需要上传完整文件，因此会增加一次上传时间。
6. 等待导入结果，并在数据集列表确认记录数。若导入部分失败，查看错误提示中的成功/失败数量；数据集记录数按成功写入数更新。修复问题后重新上传同一文件时，已写入记录会作为重复项跳过。

### 配置标签体系

1. 打开“标签体系管理”，点击“新建标签体系”。
2. 填写名称和说明，并输入标签配置 JSON。至少配置 2 个标签；每项包含唯一 `code`、标签 `name` 和十六进制颜色 `color`。
3. 点击“创建体系”。更新现有体系后点击“保存并创建新版本”；版本历史会记录修改人和时间。已创建任务使用其指定的标签体系。

### 创建和分配标注任务

1. 打开“项目与任务管理”下的“任务列表”，点击“创建任务”。
2. 填写任务名称，选择数据集和标签体系，并选择当前项目成员作为负责人。
3. 设置优先级、截止时间和标注说明；说明会显示在标注工作台，帮助执行人员理解要求。
4. 点击“创建任务”。新任务进入“待标注”状态，任务列表可查看负责人、标注进度、状态和截止时间。
5. 更换负责人或暂停/恢复任务时，先在下拉框选择目标值，再确认二次提示。也可点击“自动分配”，由系统为任务选择负责人。
6. 同一任务最多包含 10,000 条数据。任务列表中的“任务分配”已并入任务列表，不需要切换到单独页面。

任务状态由业务流程推进：记录全部标注或跳过后，有待审核标注时进入“待审核”，若全部记录均跳过则自动完成；审核退回会进入“已退回”，重新标注后再次提交审核；所有记录审核通过后任务自动完成。“待审核”和“已完成”由审核流程管理，不能手动设置。

任务负责人应为项目成员；若负责人下拉列表为空，先联系项目管理员将合适账号加入该项目。

## 5. 标注员：执行任务

1. 登录后打开“数据标注”下的“数据打标”。
2. 在“当前标注任务”中选择分配给自己的任务。列表会显示任务名称、状态和负责人；选中任务后可查看任务说明。
3. 从“数据队列”选择一条记录，在工作区阅读内容及“标注规范”。
4. 根据标签体系选择合适标签。点击“立即保存”，或点击“保存并下一条”保存后继续处理下一条。系统也会自动保存标注变更；若出现保存错误，请使用“重试保存”并确认保存状态。
5. 使用“撤销 / 重做”或快捷键 `Ctrl/⌘ Z`、`Ctrl/⌘ Shift Z` 调整标签；方向键切换数据，数字键 `1/2/3` 快速选择标签。
6. 数据包含图像、音频或视频标注信息时，在多模态标注工具中按页面提供的控件补充标注。
7. 无法处理当前记录时，可点击“跳过此条”；发现内容问题或规则疑问时，选择异常类型并填写说明后点击“提交反馈”。
8. 暂停或继续任务使用任务选择区域旁的按钮。已暂停任务不能继续标注或请求 AI 建议。

如果启用了 AI 预标注，可点击“AI 预标注”查看建议和置信度；建议不会自动写入结果，需人工判断并点击“采用建议”，再保存。AI 功能可能未启用；此时请按标签规范人工标注。

## 6. 审核员：质量审核

1. 打开“质量管理”下的“质检任务”，在“审核状态”选择“待审核”；可按数据集、标注人和标注日期筛选，并用分页浏览结果。
2. 阅读数据内容和已有标注；点击“自动质检”查看基础规则检查结果。自动质检只提供提示，审核员仍需根据标注规范作出判断。
3. 确认无误后点击“审核通过”。
4. 需要修改时，在审核意见框写明具体原因，再点击“退回修改”。审核意见不能为空；明确指出问题有助于标注员修正。退回后任务会回到标注流程，重新提交的记录将重新进入待审核队列。
5. 通过状态筛选可查看“已通过”或“已退回”记录。
6. “质检报告”可查看待审核、审核完成、通过、退回和通过率概览及最近审核记录；“质检规则”页签介绍当前系统自动检查项。

自动质检包含内容完整性、内容长度、标注结果、标注人信息和当前数据集内重复内容等检查。系统规则固定执行，页面不提供自定义规则编辑。

## 7. 数据分析员：查看、统计和导出

### 查看数据

打开“数据标注”下的“数据展示列表”，可按编号或内容搜索，按数据集及标注状态筛选，并按最新数据或低置信度排序。点击“查看详情”查看记录内容、字段和标注信息；使用上一页 / 下一页浏览结果。调整筛选或排序后，列表会从第一页重新加载。

### 查看统计

打开“统计分析”，选择项目范围（若有多个可访问项目），查看数据总量、已标注/待标注数量、完成率、已审核数量、逾期任务、标签分布和人员工作量。指标按当前账号有权访问的数据范围统计。

### 导出数据

打开“数据交付与导出”下的“数据导出”，选择数据集（或全部可访问数据）、标注状态和 JSONL/CSV 格式，然后点击“下载标注数据”。导出范围受账号项目权限限制。请妥善保存下载文件，并按组织的数据安全要求传递或删除。

## 8. 通用页面与数据说明

- **标注工作台**：提供当前账号信息和常用服务入口；快捷入口会按角色权限隐藏不可访问功能。
- **数据详情**：从数据展示列表点击“查看详情”进入。
- **操作日志**：管理员可在“系统设置”下查看已记录的数据集、任务、标签体系和用户权限变更。
- **标注规范、操作指南、部分平台设置**：若页面显示“演示页面”或“业务数据和在线操作尚未接入”，说明该菜单当前为说明/占位页面，不提供实际业务操作。
- **隐私保护**：系统默认对手机号、邮箱和身份证号进行脱敏展示。不要在任务说明或异常反馈中粘贴不必要的敏感信息。

## 9. 常见问题

| 现象 | 建议处理 |
|---|---|
| 看不到某个菜单 | 请管理员核对账号角色；菜单仅显示当前角色允许的功能。 |
| 看不到项目、数据集或任务 | 确认账号已被添加为该项目成员，且任务已分配给当前账号。 |
| 提示无权访问 | 刷新后重新登录；若仍出现，请联系管理员检查角色和项目成员关系。 |
| 菜单加载失败或显示服务器错误 | 先点击“重试”或刷新页面；如果问题持续，请将发生时间和页面名称提供给管理员检查后端日志。 |
| 数据加载失败，提示 Elastic 不可用 | 联系管理员检查 Elasticsearch 服务、连接配置及索引状态。 |
| 找回密码收不到验证码 | 确认邮箱已完成验证，并检查垃圾邮件；若仍未收到，请联系管理员检查 SMTP 配置。 |
| 导入失败或请求过大 | 确认文件格式受支持、文件不超过 1 GB、单条记录不超过 50 MB；大文件还要求部署端有足够临时磁盘及请求体上限。 |
| 标注保存失败 | 检查网络连接并点击“重试保存”；确认任务没有暂停、账号仍有项目访问权限。 |
| 页面显示“演示页面” | 该菜单暂为说明占位，不代表已接入业务操作；请使用本手册中对应的实际业务页面。 |

如需管理员协助，请提供账号、角色、项目名称、页面名称、操作步骤、发生时间和完整错误提示；不要发送密码、验证码、会话 Cookie 或 API 密钥。
